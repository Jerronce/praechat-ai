# PraeChat AI

A polished browser-based AI chat interface concept with prompt chips, conversation history, and a local smart-response simulator.

## Features

- Premium chat interface
- Prompt suggestion chips
- Local response simulation
- Conversation history panel
- Works directly in the browser

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates conversational UI design, interaction flow, front-end state management, and AI product thinking.
